# ネットワーク運用（nwc-poc）

ラボのネットワークを監視し、異常を見つけて、修復案を人が承認する PoC で使う言葉。

## 言葉

### 障害とアラート

**アラートの通知**:
Grafana か Splunk が、ある要素の状態（発火 firing か解消 resolved）を 1 回知らせたもの。同じ障害について何度も、また両方から届くことがある。
_Avoid_: イベント、異常イベント

**障害**:
ある要素（回線、BGP のセッション、IS-IS の隣接、機器）が落ちてから戻るまでの 1 回。アラートの通知を要素ごとに並べて読み取るものであって、記録の単位ではない。
_Avoid_: インシデント、異常

**異常 ID（anomaly_id）**:
障害の起きた要素を表す `<機器>#<種類>#<対象>`。同じ要素の障害は何度起きても同じ異常 ID になる。
_Avoid_: 障害 ID、発生 ID

**アラートの履歴（alert_events）**:
受け取ったアラートの通知を、届いたとおりに残した記録。「いま開いている障害」はここではなく、トポロジの状態で見る。
_Avoid_: 障害履歴テーブル、incident_events、anomaly_events
